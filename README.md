# Student Record Management System

## Project Title
Student Record Management System Using Linked List and Stack

## Description
This is a menu-driven Java console application that manages student records. Users can add, display, search, delete, update, and sort student records by GPA. The program also provides an undo feature for the last delete or update operation.

## Data Structures Used
- **Singly Linked List:** Stores student records dynamically.
- **Stack:** Stores previous student information to undo delete and update operations.

## Algorithms Used
- **Linear Search:** Searches for a student using their ID.
- **Bubble Sort:** Sorts student records by GPA in descending order.

## Features
1. Add a student.
2. Display all student records.
3. Search for a student by ID.
4. Delete a student record.
5. Update student details.
6. Sort students by GPA.
7. Undo the last delete or update.
8. View undo history.
9. Count total students.
10. Validate user input.

## Time Complexity

| Operation | Time Complexity |
|---|---|
| Insert student | O(n) |
| Delete student | O(n) |
| Search student | O(n) |
| Bubble Sort | O(n²) worst case |
| Stack Push | O(1) |
| Stack Pop | O(1) |
